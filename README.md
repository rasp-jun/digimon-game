# 디지몬게임 · 파일 아일랜드 리그

디지몬을 수집하고 배치해 자동 전투를 진행하는 팬 제작 오토배틀러 프로젝트입니다. 웹 프로토타입에서 시작해 Unity 네이티브 Android 버전과 1대1 멀티플레이 프로토타입으로 확장했습니다.

## 프로젝트 구성

| 경로 | 내용 |
|---|---|
| 루트 | 서버 없이 실행하는 웹 오토배틀러 |
| `DittochesUnity/` | Unity 6.6 기반 솔로 네이티브 버전 |
| `DittochesMulti/` | 솔로·일반·랭크 로비와 Python 매칭 서버를 포함한 멀티 버전 |
| `tests/` | 웹 게임 엔진·장비·스테이지 테스트 |
| `legacy/` | 초기 Python 프로토타입 |

Unity가 생성하는 `Library`, `Temp`, 로그와 APK 등 빌드 결과는 저장소에서 제외합니다. 멀티 실행과 서버 테스트 방법은 [`DittochesMulti/README.md`](DittochesMulti/README.md)를 참고하세요.

이 저장소는 학습 및 개인 프로토타이핑을 위한 비공식 팬 프로젝트이며, 디지몬 관련 상표와 캐릭터의 권리는 각 권리자에게 있습니다.

## 웹 버전

`실행.bat` 또는 `index.html`을 열면 플레이합니다. 인터넷과 서버가 필요 없는 디지몬 웹 오토체스입니다.

게임을 열면 솔로 플레이 로비가 표시됩니다. 쉬움·보통·어려움 난이도와 비트몬·코로몬·토코몬·어니몬 중 전설이 하나를 고른 뒤 입장합니다. 전설이는 능력치를 바꾸지 않는 꾸미기 요소이며, 전리품 회수와 승리 공격 연출을 담당합니다. PvP 승리에는 짧은 고유 공격이 재생되고 그 피해로 상대가 탈락하면 전설이별 처형 장면이 재생됩니다.

난이도는 플레이어가 만나는 AI에게 적용됩니다. 쉬움은 AI 전투력 88%와 기본 수입 -1G, 보통은 기본 수치, 어려움은 AI 전투력 112%와 기본 수입 +1G입니다. AI끼리의 전투에는 전투력 보정이 들어가지 않아 리그 순위 흐름이 과도하게 왜곡되지 않습니다.

## 스테이지

| 구간 | 진행 |
|---|---|
| 1-1 · 1-2 · 1-3 | 시작 크립 |
| 2스테이지 이후 -1 · -2 · -3 | PvP |
| 각 스테이지 -4 | 초밥집: 유닛 + 아이템 묶음 하나 선택 |
| 각 스테이지 -5 · -6 | PvP |
| 각 스테이지 -7 | 야생 수호자 크립 |

3~8스테이지도 같은 순서입니다. 최후 생존자가 승리하며, 8-7까지 남으면 체력·PvP 승수·테이머 ID 순으로 순위를 결정합니다.

## 보상과 경제

- 시작 장비와 짝수 라운드 장비 지급은 없습니다. AI도 크립·초밥집에서만 새 장비를 얻습니다.
- 크립 처치마다 독립적으로 전리품을 판정합니다: 42% 없음, 30% 작은 구슬, 20% 푸른 구슬, 8% 황금 구슬. 1스테이지 완승은 모든 판정이 빗나가면 작은 구슬 하나를 보장합니다.
- 전리품은 즉시 지급되지 않습니다. 보드에 떨어진 구슬을 선택한 전설이로 직접 눌러 회수해야 골드·장비·유닛이 들어옵니다. 회수하지 않은 구슬과 전설이 종류·위치는 저장됩니다.
- 작은 구슬은 골드, 푸른 구슬은 장비 재료, 황금 구슬은 스테이지 골드와 유닛 또는 장비를 줍니다. 유닛 공유 재고가 소진되면 황금 구슬의 유닛 보상은 생략됩니다.
- 초밥집은 유닛과 아이템을 함께 지급합니다. 2~4스테이지는 재료, 5스테이지부터는 완성 장비입니다. 유닛은 대기석, 아이템은 보관함으로 갑니다. 대기석 포화로 즉시 합성도 불가능하면 유닛 판매가만큼 골드로 전환합니다.
- 크립 적은 공유 재고를 사용하지 않으며 보상 유닛은 공유 재고에서 차감합니다.
- 전투 정산은 기본 5G + 이자(10G당 1G, 최대 5G) + 연속 보너스 + PvP 승리 1G, 경험치 +2입니다. 초밥집은 수입·경험치 정산 없이 진행됩니다.
- 크립·초밥집은 PvP 연승·연패를 바꾸지 않습니다. 테이머 지원은 2-1 · 3-1 · 4-1에 선택합니다.

PvP 패배 피해: `ceil((2 + (스테이지-2)*2 + 상대 생존 별 합계) * (1 + (스테이지-2)*0.1))`. 상대 생존 별 합계가 3이면 2스테이지 5, 3스테이지 8, 4스테이지 11 피해입니다. 크립 패배·시간 초과 피해는 스테이지 +1입니다.

## 유닛과 조작

플레이어 1명과 AI 7명, 유닛 30종, 특성 9종. 1~5코스트는 유년기·성장기·성숙기·완전체·궁극체이며 각 6종입니다. 같은 유닛 3개로 별을 올립니다. 전투 중 진화·조그레스는 없습니다. 장비 재료 4종으로 완성품 10종을 합성합니다.

각 디지몬의 공유 기물 수는 1코스트 39개, 2코스트 26개, 3코스트 21개, 4코스트 13개, 5코스트 10개입니다. 상점·보유 유닛·다른 테이머의 보유분이 모두 같은 재고를 사용하므로 여러 테이머가 같은 디지몬을 모으면 해당 디지몬이 상점에 나올 확률이 낮아집니다. 한 테이머가 특정 디지몬을 3성으로 완성하면 그 테이머의 상점에서는 해당 디지몬이 잠기며, 남은 기물은 다른 테이머에게 계속 출현할 수 있습니다.

새 리그는 레벨 1, 0골드와 유년기 유닛 1마리로 시작합니다. 플레이어는 코로몬, AI는 각자 무작위 유년기 한 마리를 받습니다. 첫 크립 전투 정산과 전리품 구슬부터 골드를 확보해 팀을 늘립니다.

크립과 PvP 전투를 마칠 때 기본 경험치 2를 받습니다. 초밥집은 전투가 아니므로 경험치를 주지 않습니다. 필요 경험치는 `1→2: 2`, `2→3: 2`, `3→4: 6`, `4→5: 10`, `5→6: 20`, `6→7: 36`, `7→8: 60`, `8→9: 68`입니다. 4골드로 경험치 4를 구매할 수 있으며 초과 경험치는 다음 레벨로 이어집니다.

클릭 또는 드래그로 유닛 이동. 장비 선택 후 아군 클릭으로 장착, 유닛 정보에서 무료 회수. 유닛당 장비 2개. `D` 리롤, `F` 경험치, `E` 판매, `Esc` 선택 취소. 상대 순위 클릭은 정찰이며 '다음 상대 보기'는 예정된 상대 또는 크립 진형으로 돌아갑니다.

전투 중에도 상점 구매·리롤·경험치 구매·상점 잠금, 대기석 정리와 판매, 장비 장착·회수·합성을 할 수 있습니다. 전장 유닛의 이동과 판매는 전투가 끝날 때까지 잠깁니다. 전투 중 발생한 별 승급과 장비 변경은 현재 싸우는 복사본을 바꾸지 않고 다음 전투부터 적용됩니다.

## 저장과 검증

준비 단계, 난이도, 전설이 선택, 초밥집 선택, 미회수 전리품 구슬과 전설이 위치가 자동 저장됩니다. 전투 중 새로고침하면 전투 직전으로 돌아갑니다. v8 저장을 사용하며 이전 저장은 덮어쓰지 않고 새 리그로 시작합니다.

Node.js 18 이상: `node --test tests/engine.test.js tests/equipment.test.js tests/stages.test.js`

`data.js`는 데이터, `engine.js`는 전투·스테이지·경제, `game.js`는 화면과 입력, `index.html`·`style.css`는 레이아웃입니다. `legacy/`는 이전 Python 프로토타입, `AUTOCHESS_RESEARCH.md`는 이전 조사 기록입니다. `update-*-v3.cjs`는 과거 변경용이므로 현재 코드에 재실행하지 마세요.
